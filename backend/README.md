# Backend (teammate-owned, separate from frontend repository)
This folder documents the intended separate backend boundary. **No backend code or fake server is provided.**
Your backend teammate can maintain a separate GitHub repository and run it on http://localhost:5000. Please agree on the API contract in ../docs/API_CONTRACT.md.
Backend must own authentication/session cookies, role and branch authorization, price resolution, VAT, transactions, printing/bridge, offline sync and audit log.
